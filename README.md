# WESAM — حاسبة بلوت

الموقع: httpt/

حاسبة عربية للجوال، بتصميم أزرق غامق، لتسجيل نقاط لنا ولهم وحفظ الجولات محليًا على الجهاز.

- `index.html`: النسخة المنشورة المستقلة، تضم التنسيق والبرمجة دون الحاجة لخادم.
- `source.zip`: ملفات React وTypeScript الأصلية وإعدادات البناء، لتعديل الموقع وإعادة بنائه.

للتطوير: فك source.zip، وثبّت المتطلبات باستخدام `npm ci` ثم نفّذ `npm run build:github`.
ارفع ملف `github-dist/index.html` الناتج إلى جذر هذا المستودع.

GitHub Pages: النشر من فرع `main` والمجلد `/ (root)`.
