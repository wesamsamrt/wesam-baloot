# WESAM — حاسبة بلوت كتطبيق

الموقع: https://washiiiiing.github.io/wesam-baloot/

اضغط «ثبّت التطبيق» أعلى الحاسبة. في المتصفحات الداعمة تظهر نافذة التثبيت ويؤكدها المستخدم. على iPhone يعرض الزر خطوات Safari: مشاركة ← إضافة إلى الشاشة الرئيسية ← إضافة.

الحاسبة تعمل دون إنترنت بعد أول زيارة ناجحة، وتحفظ النقاط على الجهاز. لا يمكن تجاوز تأكيد التثبيت الذي يطلبه المتصفح.

## ملفات النشر

ارفع هذه الملفات معًا إلى جذر المستودع: `index.html` و`manifest.webmanifest` و`sw.js` و`icon-192.png` و`icon-512.png`.
لا يكفي رفع index.html وحده لتثبيت التطبيق. يلزم فتحه عبر HTTPS وليس بالنقر على الملف المحلي.

## التطوير

يحتوي `source.zip` على ملفات React وTypeScript وإعدادات البناء. فكّه، ثم نفّذ `npm ci` وبعده `npm run build:github`. ملفات النشر تنتج في `github-dist`.
نفّذ `node scripts/check-pwa.mjs` لفحص الكاش ونطاق التطبيق والأيقونات. عند تغيير ملفات التطبيق المخزنة مسبقًا، حدّث رقم الكاش في `public/sw.js`.

GitHub Pages: النشر من فرع `main` والمجلد `/ (root)`.
